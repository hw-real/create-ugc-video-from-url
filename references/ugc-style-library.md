# UGC Style Library

Choose ONE format per video. Match the format to the evidence available and the product's nature. One primary message beats cramming every page feature into a short video.

## Format catalog

| # | Format | Core structure | Best when | Creator profile | Hook pattern |
|---|--------|----------------|-----------|-----------------|--------------|
| 1 | **Problem–solution demo** | Show pain → introduce product → demonstrate result → CTA | A visible pain point and a demonstrable result; before/after is *shown*, not claimed | Relatable sufferer turned user | "If this bothers you too…" |
| 2 | **Creator testimonial** | Subjective experience → why it works for them → honest limits → CTA | Credible personal experience; no fabricated review claims | Genuine user persona | "I've been using this for…" |
| 3 | **Unboxing / first impression** | Packaging → reveal → tactile first reaction → CTA | Packaging and tactile discovery are part of the appeal | Curious, excited creator | "Let's see what's inside…" |
| 4 | **Tutorial** | Quick tip → step-by-step use → result → CTA | Correct use is the main value (tools, skincare routine, appliances) | Helpful expert/friend | "Here's how I actually use…" |
| 5 | **Three reasons** | Hook → reason 1, 2, 3 (fast beats) → CTA | Several supported benefits need quick structure | Energetic list-maker | "3 reasons I picked this" |
| 6 | **Lifestyle / Vlog integration** | Context scene → product naturally appears → benefit in real life → CTA | Identity and context drive desire (fashion, home, travel) | Aspirational creator | A moment, then the product |
| 7 | **Product-first money shot** | Hero shot → slow reveal/rotation → key feature beats → CTA | No people needed; references limited to product images | Camera/anonymous presenter | Visual-only hook |
| 8 | **Try-on / product-in-hand** | Product-in-hand or on-person → feature close-ups → CTA | Apparel, accessories, cosmetics; uses real product images | Visible person/model | "Wait for the [feature]" |

## Selection rules

1. **Evidence first.** If the page proves a visible problem and a result, choose #1. If it only proves design/material facts, choose #7 or #5. If apparel/cosmetics and page images show the product on a body, choose #8.
2. **Audience fit.** Skincare/beauty → testimonial or tutorial. Home/gadget → demo or unboxing. Fashion → try-on or lifestyle.
3. **Reference constraint.** Few or low-quality references → lean product-first (#7) or keyframe-backed formats rather than action-heavy demos.
4. **Regulated categories** (health, food claims, finance) → formats that demonstrate mechanics rather than assert outcomes; avoid #1's implied results and #2's outcome claims.

## Common anti-patterns

- Mixing two formats in one 15s video (e.g., unboxing *and* tutorial). Pick one spine.
- Asserting outcomes the page never states (result claims belong to Forbidden unless verified).
- A hook that spends the first 2 seconds on logos/greetings instead of a reason to stay.
- Voice-over that restates on-screen text word-for-word.
- CTA that is absent, generic ("buy now"), or disproportionate to the video's promise.
